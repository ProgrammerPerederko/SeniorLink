## Critério de conclusão de uma tela

Uma tela entra como concluída quando:

- visual aprovado;
- navegação funcionando;
- validações necessárias funcionando;
- estados vazios/erro tratados;
- persistência implementada quando necessária;
- permissões tratadas quando necessárias;
- teste realizado no dispositivo;
- documentação atualizada.
