# SeniorLink — Android MVP

Kotlin + Jetpack Compose. Protótipo de 16 telas convertido em fluxo funcional local.

Inclui splash/onboarding, login/cadastro local, Home, perfil persistido, GPS, lembretes, SOS/telefone, tutoriais, contatos e configurações/acessibilidade.

Abra a raiz no Android Studio, sincronize o Gradle e execute no aparelho.
