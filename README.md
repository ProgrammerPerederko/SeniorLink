# SeniorLink — Android MVP

Aplicativo Android em Kotlin + Jetpack Compose baseado no protótipo de telas do SeniorLink.

## Incluído

- Splash e onboarding em 3 etapas
- Login local, cadastro e boas-vindas
- Home com navegação inferior
- Perfil com persistência local
- Localização via GPS e abertura em mapa
- Lembretes persistentes com alarme e notificações
- Emergência com confirmação, discador e compartilhamento de localização
- Aprender com tutoriais
- Contatos de confiança com adicionar, editar, excluir e ligação
- Configurações e texto maior para acessibilidade

## Teste

Abra a pasta no Android Studio, sincronize o Gradle e execute no aparelho Android.

O MVP usa armazenamento local para permitir o teste sem backend.
